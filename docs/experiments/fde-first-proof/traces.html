Why the raw number needs three framings

It's estimated, not actual. The provider didn't return per-session actuals to the telemetry store, so this is the standard estimate. Read it as "≈ $63," not a precise invoice.

Cache is the real story. ~100M cache-read tokens (steep discount) against ~9.4M fresh input. Without prompt caching this would have cost several times more. The single Aug 10 session is half the total cost — K3's 1M-token context re-reads the same large Lean files on every iteration, and cache absorbs most of it.

The inefficiency is nameable and fixable. That Aug 10 cost is the price of re-ingesting whole files. A more established setup — the lean4-formalization skill that now exists didn't exist on Aug 7 — would cut it substantially. "Cheaper in the future" is a concrete claim, attached to this number.
